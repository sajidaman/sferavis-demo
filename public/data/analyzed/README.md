# User-supplied analysis products

These CSV tables and tracklet diagnostic plots were supplied for display in the Sferavis atlas and are published here as provided. Sferavis has not independently reproduced or validated the source pipeline, measurements, cross-matches, or classifications. Use the table descriptions in the app as navigation aids, not as a scientific validation or provenance statement.

The tables are loaded on demand from the analysis-data explorer. The atlas overlay uses `tracklets_known_check.csv`, `tracklet_members.csv`, and (when enabled) `3_detections_filtered.csv`. `diagnostics/candidate_XXXX.png` contains the supplied plot for the tracklet with the matching numeric ID.

The attached PDF was not included because it is a literature compilation and does not document these CSV schemas.
